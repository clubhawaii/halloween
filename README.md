# 클럽하와이 2026 할로윈 한정판 카드 포토부스

학생 사진 + 미리 만든 카드 PNG를 브라우저 안(Canvas)에서 합성해 저장·인쇄하는 정적 웹앱입니다.
서버·DB·로그인·AI를 쓰지 않으며, 학생 데이터는 외부로 전송되지 않습니다.

## 1. 실행 방법

| 환경 | 방법 |
|---|---|
| **Windows PC/노트북** | `start-windows.bat` 더블클릭 → 브라우저가 `http://localhost:8731` 로 열림. 행사 중 검은 창은 닫지 마세요. |
| **Mac** | `start-mac.command` 더블클릭 (처음 한 번 "확인되지 않은 개발자" 경고가 뜨면 우클릭 → 열기) |
| **웹서버(HTTPS)** | 폴더 전체를 그대로 업로드 (Netlify, GitHub Pages, 회사 서버 등). 태블릿은 이 방식 권장 |

> `index.html` 을 더블클릭해서 바로 열면(file://) 브라우저 보안 때문에 카드 이미지 저장이 막힙니다.
> 반드시 위 방법 중 하나로 실행하세요. (폴더 저장·카메라는 localhost 또는 HTTPS에서만 동작)

권장 브라우저: **PC/노트북 최신 Chrome 또는 Edge** — 카드 저장(다운로드 폴더)과 인쇄 때 다운로드 폴더 바로 열기까지 전체 기능 지원.
Safari·Firefox·태블릿 브라우저는 일반 다운로드 + 파일 직접 선택 방식으로 자동 전환됩니다.

## 2. 파일 구조

```
index.html   화면 14개 (SPA)
styles.css   UI 디자인 + 인쇄용 CSS(A4 세로, 2열×4행)
config.js    ★ 수정은 대부분 여기서
app.js       동작 로직
assets/card-01.png ~ card-06.png   카드 시안 (현재 임시 시안)
```

## 3. 디자이너 카드 PNG 교체 방법

1. 6장 모두 **같은 크기**의 PNG로, 학생 사진이 보일 부분은 **투명**하게 비워주세요.
2. `assets/card-01.png ~ card-06.png` 를 같은 이름으로 덮어쓰기.
3. `config.js` 에서 아래 값만 새 시안에 맞게 수정:
   - `CARD.width / height` → PNG 픽셀 크기
   - `NICKNAME` / `ACADEMY_NAME` → 공통 글꼴·크기·색·maxWidth(넘치면 자동 축소)
   - `ACADEMY_NAME.curve.radius` → 학원명이 리본을 따라 휘는 정도 (작을수록 많이 휨)
   - `CARD_TYPES[].layout` → 시안마다 다른 사진 영역(photoArea), 닉네임 y, 학원명 y
   - `CARD_TYPES` → 타입 이름(name), 파일명용 표기(fileLabel), 파일 경로, 결과 화면 문구(tagline)

저장되는 카드는 항상 PNG 원본 해상도로 만들어집니다(화면 미리보기 크기와 무관).

## 4. 질문·점수 수정

`config.js` → `QUESTIONS`. 각 답변의 `scores: { type03: 2, type04: 1 }` 처럼 타입별 점수를 줍니다.
최고점 타입이 결과이며, 동점이면 답변 조합으로 정해진 규칙에 따라 하나가 결정됩니다(같은 답변 = 같은 결과).
현재 점수표(4문항)로 81가지 답변 조합 전체를 계산하면 6타입이 13~15회씩 고르게 나옵니다.

## 5. 저장 방식

- 기본(`config.js` → `SAVE.mode: "download"`): [이미지 저장]을 누르면 설정·허용 창 없이 바로 **다운로드 폴더**에 저장됩니다.
- 파일명: `학원명_Halloween_이름_닉네임_타입.png` (예: `김지수주먹밥_Halloween_김민지_MINJI_CANDY_WIZARD.png`). 같은 이름은 브라우저가 ` (1)` 을 붙여 저장합니다.
- 전용 폴더에 모으고 싶다면 `SAVE.mode: "folder"` 로 바꾸면, 첫 저장 때 폴더를 한 번 고르고 그 안에 `학원명_Halloween_Cards` 폴더를 만들어 저장합니다.
  (바탕화면·다운로드·문서 폴더 "자체"는 Chrome 보안 정책상 선택할 수 없습니다.)

## 6. 인쇄

상단 [카드 인쇄하기] → [카드 이미지 선택]을 누르면 다운로드 폴더가 열림 → 카드 이미지 최대 8장 선택 → [인쇄 레이아웃 만들기] → [전체 카드 인쇄]
인쇄 창에서: 용지 A4 / 세로 / 배율 기본(100%) / 여백 없음 → 프린터 또는 "PDF로 저장".
